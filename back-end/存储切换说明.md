# 文件存储：本地 ↔ 阿里云 OSS 切换说明

图片(手办)与视频(课堂录像)统一走 `StorageService` 抽象,**业务代码与切换无关**。

## 本地 oss-emulator（开发,当前默认）

开发环境用阿里云官方开源的 [oss-emulator](https://github.com/aliyun/oss-emulator) 在本机跑一个 OSS 协议模拟器(装在 WSL Ubuntu 内,**手动启动,未设自启**):

```bash
# 启动(在 Windows 任意终端执行;数据存 ~/oss-emulator/store,端口 10086)
wsl -d Ubuntu -- bash -c "cd ~/oss-emulator && ruby bin/emulator -r ~/oss-emulator/store -p 10086"

# 停止
wsl -d Ubuntu -- pkill -f bin/emulator
```

- 配置在 `application-dev.yml`(不入库):`app.storage.type=oss`,endpoint `http://127.0.0.1:10086`,bucket `dance-studio-dev`,AK/SK 随便填(模拟器不校验)。
- `OssStorageService` 检测到 IP/localhost endpoint 自动切 **path-style** 访问(`setSLDEnabled(true)`),直链/签名 URL 均为 `http://127.0.0.1:10086/{bucket}/{key}` 形式;云端 endpoint 仍用虚拟主机风格,上线零改动。
- 限制:模拟器只支持数据面接口(put/get/copy/multipart 等),**不校验签名与过期**——签名 URL「过期拒访」等鉴权语义无法本地验证;STS、bucket 生命周期等管理接口不支持。
- 已知坑:用 curl 测试时默认 Content-Type 是 `application/x-www-form-urlencoded`,会触发模拟器预读请求体导致对象存成 0 字节;Java SDK 上传带真实 Content-Type,不受影响。bucket 名需 ≥3 字符。
- 切回纯本地磁盘存储:把 `application-dev.yml` 的 `app.storage.type` 改回 `local`(或删掉 app 段)重启后端。

## 本地磁盘存储（备选）
- 配置 `app.storage.type=local`。
- 上传的文件保存到 `back-end/uploads/`,通过 `http://localhost:8080/files/...` 访问。
- `signedUrl()` 直接返回原地址(本地不签名)。
- 微信开发者工具需勾选「不校验合法域名」才能访问 localhost。

## 上线（阿里云 OSS）
只改**配置/环境变量**,不动代码:

```bash
STORAGE_TYPE=oss
OSS_ENDPOINT=oss-cn-shanghai.aliyuncs.com   # 你的地域 endpoint
OSS_BUCKET=your-bucket
OSS_AK=你的AccessKeyId
OSS_SK=你的AccessKeySecret
OSS_URL_EXPIRE=3600                         # 视频签名URL有效期(秒)
```

启用后 `OssStorageService` 自动生效(`@ConditionalOnProperty`):
- **手办图片**:`putObject` 后返回直链。建议该 bucket 设公共读,或绑 CDN 域名。
- **课堂视频**:同样上传到 OSS;播放时 `mp/videos/{id}/play` 会调用 `signedUrl()` 生成**带时效签名 URL**。建议视频用**私有读写** bucket,保证仅授权学员可看。

## 小程序合法域名
上线后在「微信公众平台 → 开发管理 → 服务器域名」配置:
- request 合法域名:你的后端 API 域名(https)
- downloadFile / 视频播放域名:OSS / CDN 域名(https)

## 安全建议
- AK/SK 用 RAM 子账号 + 最小权限,只授该 bucket 读写。
- 更推荐用「STS 临时凭证 + 服务端直传签名」,避免 AK/SK 落到服务器配置;当前实现为服务端中转上传(够用,后续可升级 STS 直传)。
